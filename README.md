# -Basic-Sales-Summary-from-a-Tiny-SQLite-Database-using-Python
This project uses Python to demonstrate how to extract and visualize sales data from a small SQLite database.
The script connects to a database (sales_data.db), runs SQL queries to calculate total quantity sold and total revenue by product, displays the results using print statements, and visualizes product-wise revenue using a basic bar chart with matplotlib. This task highlights integration between SQL and Python for simple data analysis and reporting.
